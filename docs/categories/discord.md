| Template | Description | Department |

| [Discord AI-powered bot](https://github.com/ahmedfawzyjr/N8N-Templates/blob/main/Discord/Discord%20AI-Powered%20Bot.json) | This workflow creates an AI-powered Discord bot that categorizes user messages (success story, urgent issue, ticket) and routes them to the appropriate department (customer success, IT, customer support). | Customer Support |
| [Post New Live Tennis Matches to Discord on a Schedule](https://github.com/ahmedfawzyjr/N8N-Templates/blob/main/Discord/Post%20New%20Live%20Tennis%20Matches%20to%20Discord%20on%20a%20Schedule.json) | Every 5 minutes, fetches the currently live tennis matches from the Live Tennis API, keeps only the ones newly in progress (deduplicated across executions), and posts a one-line alert (players and match status) to a Discord channel via a webhook.
