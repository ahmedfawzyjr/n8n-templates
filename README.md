## ⚙️ Getting Started & Installation

### Prerequisites
- n8n CLI / Docker

### Installation Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ahmedfawzyjr/n8n-templates.git
   cd n8n-templates
   ```

2. **Install Dependencies**:
   ```bash
   npm install -g n8n
   ```

3. **Configure Environment Variables**:
   ```bash
   cp .env.example .env
   ```

4. **Run the Application**:
   ```bash
   n8n start
   ```
