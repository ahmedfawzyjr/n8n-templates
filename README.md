## ⚙️ Getting Started & Local Setup

### Prerequisites
- n8n CLI / Docker

### Installation & Run Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ahmedfawzyjr/n8n-templates.git
   cd n8n-templates
   ```

2. **Install Dependencies**:
   ```bash
   npm install -g n8n
   ```

3. **Configure Environment**:
   ```bash
   cp .env.example .env
   ```

4. **Run Application**:
   ```bash
   n8n start
   ```
